# VERMIL Portal



SPA-приложение игрового портала вымышленной RPG-франшизы VERMIL. Реализовано в рамках итогового проекта по дисциплине "Веб-программирование и дизайн".



## О проекте



VERMIL Portal — веб-приложение, посвященное серии мрачных RPG-игр о выживании нечисти в Европе XVII века. Проект реализован как полноценное SPA-приложение с клиент-серверной архитектурой.



## Основные возможности



- регистрация и авторизация пользователей;

- JWT-аутентификация;

- работа с PostgreSQL;

- каталог игр серии;

- система комментариев;

- корзина магазина;

- адаптивный интерфейс;

- динамическое обновление контента;

- глобальное управление состоянием;

- анимации интерфейса.



## Используемые технологии



### Frontend

- React

- React Router DOM

- Context API

- Bootstrap 5

- Framer Motion

- Axios



### Backend

- Node.js

- Express.js

- PostgreSQL

- JWT

- bcrypt

# Установка проекта



## 1. Установить зависимости frontend



```bash

cd client

npm install

```



## 2. Установить зависимости backend



```bash

cd server

npm install

```



---



# Настройка PostgreSQL



Создать базу данных PostgreSQL и указать параметры подключения в файле `.env`.



---



# Запуск проекта



```bash

cd project

npm start

```
